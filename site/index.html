A voice agent that waits for its turn.

Roundtable joins a multi-person LiveKit call as one participant. It tracks who said what, decides whether a line is meant for it, waits for a real gap, and stops the moment someone talks over it. Every choice it makes is logged with the reason.

    Deciding when to talk

    The floor manager is a pure state machine with no LiveKit imports. apply folds transcript and voice-activity events into state. evaluate returns one of four verdicts (wait, speak, stop, consult), and each carries the reason the replay shows. Because it is pure, every rule is tested against scripted timelines in milliseconds.

    700 ms
    gap after someone addresses the agent, before it answers
    1.5 s
    silence after an unanswered group question before it answers
    250 ms
    of speech over the agent that stops playback at once
    1.2 s
    quiet after an overlap before it starts again
    2 s, 20 s
    silence before asking the LLM gate, and at most one gate call per 20 s

    Addressing needs no model. The agent's name counts when it is used bare, or as @name. After "the", "a" or "our" it is a noun ("let's take it to the roundtable"), unless the line opens with it and a comma follows. A participant's name counts as addressed only when a line opens with it. Three alternating turns between two people count as a back-and-forth, so the agent backs off from questions that are not its own.

    Standup proxy mode is the second recorded scenario. It answers to an absent colleague's name, delivers the prepared update once, answers follow-ups only from the notes, and says it will take anything else back to them.

    How the pieces connect

    Each person gets their own audio track, voice detector and transcription task, so a slow transcription never delays a barge-in.

    Run it locally

    One command starts LiveKit in Docker, joins three synthesised speakers and asserts the agent's behaviour from its own log. It needs macOS (for say), Docker, uv and pnpm. 

    make install          # uv sync + pnpm install
make test             # 41 unit tests: floor timelines, meeting memory, prompts, token API
make demo             # keyless end-to-end run; prints the transcript, decisions and checks

    No keys are needed. The demo pins a scripted LLM and local speech models, so it never reaches a cloud provider. The LiveKit key and secret in the defaults are the livekit-server --dev pair. They are for local development only. Production needs real keys and a real secret.

    Limits

    • Captions appear after a speaker pauses, not word by word. Streaming speech-to-text would help.
    • Speaker-level echo is not suppressed. If a microphone hears the agent's speakers, it can barge in on itself. Headphones are the reliable fix.
    • A bare name mid-sentence still counts ("I think roundtable is good" addresses it). Only determiner-led uses are excluded.
    • Speaker identity is the display name, so two people with the same name merge.
    • Thresholds were tuned on one scripted meeting, not measured on real ones.
    • The Anthropic and OpenAI-compatible LLM paths and the cloud speech adapters are not exercised. They have no keys here.
    • The demo's simulated speakers use macOS say. The agent itself runs anywhere.
